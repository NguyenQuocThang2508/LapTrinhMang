========================================
LỆNH CHẠY GAME TRÊN MÁY KHÁC
========================================

📍 BƯỚC 1: CÀI ĐẶT
========================================

Windows:
--------
Double-click: SETUP.bat

Hoặc chạy lệnh:
pip install -r requirements.txt
python create_sounds.py

Linux/Mac/Git Bash:
-------------------
pip install -r requirements.txt
python create_sounds.py

========================================
📍 BƯỚC 2: CHẠY GAME
========================================

CÁCH 1: Dùng file batch (Windows - Đơn giản nhất)
--------------------------------------------------
Double-click: start_game_with_audio.bat

CÁCH 2: Chạy từng bước (Tất cả hệ điều hành)
--------------------------------------------

Terminal 1 - Server:
--------------------
cd "đường_dẫn_đến_thư_mục_game_multiplayer"
python -m server.main

Terminal 2 - Client (mở terminal mới):
--------------------------------------
cd "đường_dẫn_đến_thư_mục_game_multiplayer"
python -m client.main

Khi được hỏi "Bật âm thanh?", nhập: Y

========================================
📍 LỆNH KIỂM TRA
========================================

Kiểm tra Python:
python --version

Kiểm tra cài đặt:
pip list | grep pygame

Kiểm tra âm thanh:
python test_audio.py

Kiểm tra server:
netstat -ano | grep 5000

========================================
📍 XỬ LÝ LỖI
========================================

Lỗi "No module named pygame":
pip install pygame

Lỗi "No module named numpy":
pip install numpy

Lỗi "Address already in use":
→ Đổi port hoặc tắt ứng dụng đang dùng port 5000

Lỗi "Connection refused":
→ Kiểm tra server đã chạy chưa
→ Kiểm tra firewall

========================================
📍 CHƠI MULTIPLAYER TRÊN MẠNG
========================================

1. Tìm IP máy server:
   Windows: ipconfig
   Linux/Mac: ifconfig

2. Sửa file: client/src/config.py
   SERVER_IP = "192.168.x.x"

3. Đảm bảo firewall cho phép port 5000
